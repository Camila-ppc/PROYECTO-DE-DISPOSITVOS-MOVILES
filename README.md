# UCB Perdidos
App móvil (Flutter) para reportar y encontrar objetos perdidos en la universidad, con IA.

## Correr
1. `flutter create ucb_perdidos` (genera android/ios)
2. Reemplazar `lib/` y `pubspec.yaml` por los de este repo
3. `flutter pub get && flutter run`
